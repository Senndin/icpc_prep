# ICPC Prep

Програмна система для автоматизації роботи з даними про підготовку студентів до олімпіад з програмування формату ICPC.
Курсовий проєкт з дисципліни «Програмування», ХНЕУ ім. С. Кузнеця, 2026.

## Можливості

- банк олімпіадних задач з тегами та складністю: додавання, редагування, видалення, пошук і фільтри;
- завантаження задач з архіву Codeforces через відкритий API;
- імпорт та експорт банку задач у файли JSON і CSV;
- команди формату ICPC (до трьох студентів і тренер);
- тренування з таблицею результатів за правилами ICPC (штраф 20 хв за невдалу спробу);
- облік спроб: вручну або синхронізацією з Codeforces;
- особиста статистика та рекомендації задач за рівнем;
- ролі: студент, тренер, адміністратор.

## Встановлення

Потрібен Python 3.10 або новіший.

**Windows:** запустіть `install.bat`, потім `run.bat`. Сценарій встановлення сам перевіряє, чи є на комп'ютері Python 3.10+: якщо є, нічого зайвого не встановлює; якщо немає, пропонує встановити його через winget. `run.bat` можна запускати й одразу: за потреби він сам виконає встановлення.

**Linux / macOS:**

```bash
./install.sh
./run.sh
```

Відкрийте http://127.0.0.1:8000/

## Тестування

```bash
python manage.py test -v 2
```

У наборі 46 тестів: форми, таблиця ICPC, імпорт та експорт, Codeforces API (з імітацією мережі),
контроль доступу та час відгуку сторінки банку з 1000 задач.

## Налаштування через змінні середовища (необов'язково)

| Змінна | Призначення | За замовчуванням |
|---|---|---|
| `DJANGO_SECRET_KEY` | секретний ключ Django | навчальний ключ |
| `DJANGO_DEBUG` | `1` — режим налагодження, `0` — вимкнено | `1` |

Для локального запуску нічого задавати не потрібно.

## Структура

```
config/      налаштування та маршрутизація проєкту
accounts/    користувачі, ролі, реєстрація, профіль
training/
  models/    класи предметної області (кожен в окремому файлі)
  services/  бізнес-логіка: таблиця ICPC, статистика, Codeforces API, імпорт/експорт
  forms/     форми з перевіркою даних
  views/     представлення
  tests/     модульні та інтеграційні тести
templates/   HTML-шаблони
static/      CSS, JS, Bootstrap (локально, без інтернету)
```
